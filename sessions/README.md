# Session Log

Each conversation (session) with this project gets a dated entry in this folder. Use entries to:

- **Resume work** after a break — read the latest entry first.
- **Understand why decisions were made** — decisions link to rune-logs and ledger entries.
- **See what's blocked and what's next** — each entry ends with next-steps.

## Format

Each file: `YYYY-MM-DD--short-title.md`

```
# YYYY-MM-DD — Title

## Context
Why this session exists, which phase/experiment it relates to.

## Work Done
- Concrete actions taken
- Files created/modified

## Decisions & Rationale
- Decision X: reason Y, linked to ledger/rune-log entry Z

## Current State
- What works
- What's blocked / what needs input
- Open questions

## Next Steps
1. ...
2. ...
```
