# Experiment Ledger

Every materially distinct experiment is recorded here. See Research Contract §3.4 for record requirements.

## Format

```
## EXP-{NNN} — {Title}

- **Date:** YYYY-MM-DD
- **Phase:** {A/B/C/D/E/F/G}
- **Hypothesis:** what question this run answers
- **Config diff:** link to config or inline diff
- **Dataset / task slice:** which gauntlets or data
- **Seed:** {seed value}
- **Budget consumed:** {time/compute}
- **Metrics:** {key results}
- **Decision:** keep / revert / modify / investigate
- **Reason:** why this decision
- **Links:** session entry, rune-log
```
